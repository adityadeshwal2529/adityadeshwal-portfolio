# Aditya Deshwal — Portfolio

A dark-themed personal portfolio built with plain HTML, CSS and JavaScript.

🔗 **Live:** [adityadeshwal2529.github.io/YOUR-REPO-NAME](https://adityadeshwal2529.github.io/adityadeshwal-portfolio/)

## Features

- Multi-language greeting preloader
- Hero name with cursor-fade effect
- Vertical timeline, tech stack grid, stats and projects sections
- WebGL dot-field background with cursor glow
- Fully responsive

## Built With

HTML5 · CSS3 · Vanilla JavaScript · WebGL
